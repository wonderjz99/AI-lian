# AI 经纬

中国 AI 公司关系地图。第一版为静态网页，支持五层产业地图、公司搜索与双选、产业 / 资本关系切换、关系证据、共同报道 / 各自动态及市值辅助模式。

## 本地运行

需要 Node.js 22.12 或更新版本、npm。首次安装：

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:5173/ 。若开发服务未检测到数据文件变更，停止后重新启动。

生产构建与本地预览：

```sh
npm run check
npm run preview
```

预览默认 http://127.0.0.1:4173/ 。`dist/` 是完整静态产物，可以交给静态托管平台；当前没有公开部署。网页不需要账号、密钥、数据库或运行时外部 API。外部来源只在用户打开原文时访问。

## 如何探索

- 点地图节点，或搜索中文、英文、别名及已收录的股票代码，例如“智谱”“GLM”“02513”。
- 选第二家公司查看双方关系和共同报道；第三家替换第二家。点已选公司标签或再次点节点可取消，重置恢复默认。
- 地图按产业 / 资本视图筛选，右侧始终保留双方全部已收录关系。点连线或关系摘要查看证据。
- 无连线仍可双选。可试“硅基流动 × 月之暗面”，查看有共同报道但没有正式关系线的情况。
- 可试“智谱 × 联想集团”“壁仞科技 × 硅基流动”查看投资依据；“阿里巴巴 × 平头哥”查看子公司关系。
- 新增“阿里巴巴 × 智谱”“阿里巴巴 × MiniMax”“联想集团 × 沐曦”等资本关系；“壁仞科技 × 智谱”“摩尔线程 × DeepSeek”可查看模型适配新闻，但不会因此生成商业关系线。
- 默认等大；切换市值模式后，虚线圆代表缺少可比快照。公司市值不代表 AI 业务规模。
- 手机可搜索、拖动 / 缩放地图，详情在底部抽屉中阅读。抽屉可收起，长内容在抽屉内滚动。

## 数据覆盖与限制

- 数据版本 **1.1.0**，资料截止 **2026-10-09**：36 家公司、21 条关系（13 条资本、8 条产业）、26 个事件、27 篇来源报道。五层覆盖，优先模型、算力硬件及代表性港股；金山系与金蝶暂缓。
- 新闻以 2026-04-09 至截止日为近期窗口，较早公告显示“历史依据”。这是人工整理的少量固定资料，未收录不等于现实中不存在。
- 每家公司都有来源、身份说明和分类理由。产品、品牌及多地股票代码不另建公司；独立子公司平头哥单独注明集团关系。
- 市值快照 **2026-03-31**，目前仅腾讯有核实过的可比总市值，来自淡马锡披露的新加坡元约值，使用法国央行同日交叉汇率转人民币。其他公司为 null。面积按对数压缩并设上限，不是严格比例，不混入融资估值，不加总母子公司或 A/H/ADS 市值。
- 关系状态和比例对应证据日期。例如阿里与月之暗面的 36% 是 2024-03-31 的历史记录，并非当前比例。集团战投记录不等于集团直接持股，具体实体未收录时会注明。
- 联合技术工作、开源模型适配与模型上架不自动成为战略合作或采购关系。

## 更新资料

正式数据位于 `src/data/`，契约见 `src/lib/schema.ts`：

| 文件 | 内容 |
| --- | --- |
| companies.json | 稳定身份、角色、分类、产品、来源、证券、市值 / 估值 |
| relationships.json | 起终点、类型、方向、状态、日期及证据文章 |
| events.json | 合并后的事件、实质涉及公司、引用文章 |
| articles.json | 原始来源、发布时间、查阅日、证据摘要、历史标记 |
| metadata.json | 版本、资料截止日、新闻窗口、市值日期、覆盖和口径 |

先核对原文，再编辑相关文件，更新元数据并运行 `npm run check`。未知数值使用 null；不要从共同报道、名单或间接路径推断正式关系。相同事件的多篇报道放入同一个事件，不同事项分别建事件。

目前**没有本地数据库**。后续重复采集时计划用 SQLite 保存候选、去重和核对记录，再导出 JSON；网页继续使用静态快照。来源和 API 候选及数据库升级路径见 `docs/data-sources.md`。

## 验证

```sh
npm run validate:data  # 默认执行 30–40 家的全量门禁
npm run typecheck
npm test
npm run build
```

在具备浏览器运行权限的环境中执行可重复端到端用例：

```sh
npx playwright install chromium
npm run test:e2e
# 当前先验收桌面
npm run test:e2e -- --project=desktop
# 或使用已经安装的 Google Chrome
PLAYWRIGHT_CHANNEL=chrome npm run test:e2e
```

本次交付的检查命令、执行结果及桌面 / 手机浏览器证据见 `docs/verification.md`。独立 Playwright CLI 在当前受限环境启动浏览器失败，不能声称该 CLI 测试通过；测试用例保留供普通本地环境运行。

开发规则见 `AGENTS.md`，产品行为见 `docs/v1-spec.md`，当前状态见 `progress.md`。

当前先完成桌面网页，手机开发与验收暂缓。已准备新建公开仓库 `wonderjz99/AI-lian` 并使用 GitHub Pages 发布的脚本：
